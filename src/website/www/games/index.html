Every game the nodes host right now. The nodes are found on Bitcoin, from their bond announcements, and your browser checks each one before asking it anything.

Build your own game

A game is yours: you sign it, any node can host it, and the nodes check every round with your rules. No approval, no listing fee.

📜A manifestYour game's name, its rules' hashes, its client's hash and how it pays out, signed with your developer key. Its hash is the game's id.The manifest → 🧩A pluginThe rules the nodes run: a deterministic core that replays every run, or a decide function for head-to-head games like Rock Paper Scissors.Plugins and head-to-head → 🖥️Its own clientOne page you write, pinned by its hash in the manifest. The Arena page runs it and hands it the lobby, the wallet and the round.The developer API → ₿The fee splitPaid rounds: the nodes 4 %, the protocol developers 2 %, you 2 %, the protocol reserves 2 %.
