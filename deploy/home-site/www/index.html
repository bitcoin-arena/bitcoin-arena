Why it can be trusted

Nobody to trust with your sats.

01No central server

Rounds run on independent nodes. Any bonded operator can host them; no company runs the game.

02No custodian

Your stake is locked in a federation contract, not paid to an operator. No single party can take it.

03Every run replayed

The round's nodes replay every input you sent. A result counts only when enough of them sign the same one.

04Settled over Lightning

Winnings go back to your wallet as sats over Lightning. Withdraw to any Lightning wallet.

Under the hood

Built on Bitcoin, end to end.

Bonds

Every node posts a bond on Bitcoin. No bond, no seat.

Committees

Each round's committee is drawn from the bonded nodes by a Bitcoin block hash.

Replay

Games are deterministic. Nodes re-run every input and sign the result.

Custody

Stakes lock in a federation run by bonded nodes, never in one company's wallet.

Settlement

Payouts and withdrawals move as sats over Lightning.
